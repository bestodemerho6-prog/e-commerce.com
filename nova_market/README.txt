NOVA MARKET — FRONTEND DEMO
=========================
A responsive e-commerce storefront built with HTML, CSS and vanilla JavaScript.
This upgraded edition adds a custom NOVA identity, cinematic arrival animation,
scroll reveals, a cinematic video feature, and a standalone nova-logo.svg asset.

HOW TO RUN
1. Extract the ZIP.
2. Open the nova_market folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Internet is required for Google Fonts and Unsplash product photography.

INCLUDED
- 200 generated product listings across six categories
- Responsive navigation and search
- Category filtering, price filters, rating filter and sorting
- Product quick-view modal
- Wishlist and cart saved in localStorage
- Quantity controls and demo checkout interaction
- Flash-sale countdown, newsletter demo and responsive layouts
- Animated NOVA brand intro and custom SVG wordmark
- Cinematic background video feature with pause/play control
- Scroll progress indicator and restrained reveal transitions

IMPORTANT
This is a frontend prototype. Checkout, user accounts, order processing, inventory,
real-time prices and payment processing require a backend and payment integration.
Product names/prices are demo catalogue data. Product photography and the featured Pexels video are streamed from remote URLs
and require an internet connection. If a remote clip becomes unavailable, replace
the video source in index.html with a downloaded, properly licensed MP4. The Pexels
license permits use on websites; check the clip page for any additional restrictions.
